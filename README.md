# 霓虹收割者 · NEON REAPER

霓虹风格的「割草」生存游戏。在不断涌来的敌潮中存活 10 分钟，击败最终 BOSS「虚空之眼」即可通关；通关后可继续无尽模式。

**在线试玩：<https://liyi0x0.github.io/neon-reaper/>**

## 怎么玩

直接用浏览器打开（推荐 Chrome / Edge / Safari 最新版，需要 WebGL2）：

- `dist/neon-reaper.html`：单文件版，双击即可运行，可以直接发给别人
- `index.html`：开发版，直接加载 `src/` 下的源码

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 / 手柄左摇杆 / 触屏任意位置拖动 / 按住鼠标左键 |
| 攻击 | 全自动 |
| 选择升级 | 点击卡片或数字键 1–4，R 刷新选项 |
| 暂停 | Esc / P / 手柄 Start |

## 内容

- **6 位角色**：各自的起始武器与天赋
- **10 种武器**，满级（8 级）后持有对应被动并拾取宝箱即可**进化**：
  能量飞弹 → 星辉风暴（急速）· 旋转刃 → 银河环（范围）· 连锁闪电 → 雷神之怒（力量）· 棱镜激光 → 棱镜阵列（持久）· 脉冲新星 → 超新星（护甲）· 追踪导弹 → 蜂巢弹幕（多重）· 光刃斩 → 血月斩（疾风）· 冰霜领域 → 绝对零度（再生）· 奇点 → 事件视界（磁力）· 弹射飞盘 → 无限回旋（弹速）
- **13 种被动**、精英怪宝箱、磁暴 / 湮灭 / 时停 / 回复道具
- **敌潮事件**：包围圈、兽潮、自爆蜂群；**3 种 BOSS**（巨像、虫后、三阶段的虚空之眼）
- **自适应配乐**：全部由 Web Audio 实时合成（底鼓侧链、超锯齿 Pad、乒乓延迟琶音、主旋律），随游戏进程加入新声部，BOSS 战切换和声与旋律；地面网格随鼓点脉动

## 技术

- 自写 WebGL2 渲染器：所有图元为一次实例化绘制，片元着色器用 SDF 绘制霓虹形状；HDR 场景 → 多级泛光 → 合成（冲击波扭曲、黑洞引力透镜、色差、暗角、胶片颗粒）
- 结构化数组（TypedArray）实体池 + 空间网格，同屏约 1800 敌人、上万粒子保持流畅；低帧率时自动降低画质
- 无任何第三方库，无外部资源（字体来自 Google Fonts，离线时使用系统字体）

## 目录

```
index.html        开发入口
src/util.js       工具函数、设置存储
src/gl.js         WebGL2 渲染器与全部着色器
src/audio.js      音乐引擎与音效合成
src/data.js       敌人、武器、被动、角色、敌潮时间表
src/world.js      实体池、空间网格、伤害结算、粒子、掉落
src/enemies.js    敌人 AI、刷怪导演、BOSS
src/weapons.js    武器行为与投射物
src/game.js       游戏状态、升级/宝箱/进化、主更新与画面合成
src/ui.js         菜单与 HUD
src/main.js       输入、流程控制、主循环
build.mjs         打包为单文件：node build.mjs → dist/
```

修改源码后运行 `node build.mjs` 重新生成 `dist/`。
